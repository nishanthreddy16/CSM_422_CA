# Before You Submit PlantGuard AI

- [ ] Run the app in a fresh Python 3.12 virtual environment.
- [ ] Upload at least one test image per class and record what happens; do not assume every prediction is correct.
- [ ] Confirm `model/class_names.json` matches the class order used to train the saved model.
- [ ] If you retrain, save the new validation metrics and ensure screenshots/report refer to that same run.
- [ ] Verify the dataset's original source and licence before sharing the images.
- [ ] Explain the code in `train.py`, `predict.py`, `utils.py`, `app.py`, and `gradcam.py` in your own words.
- [ ] Clearly distinguish what you personally wrote/changed from code or help adapted from other sources, following your university's AI-use policy.
- [ ] Do not claim independent test accuracy unless you have evaluated on a separate test set.
- [ ] Treat treatment text as general information and seek qualified advice for real crop problems.
